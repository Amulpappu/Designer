# K. Lohith | Gamer & Developer Portfolio 🎮

A gaming-themed personal portfolio with a terminal-style intro, live Discord and Steam status, and a built-in chat assistant.

## ✨ Features
- **Boot-screen intro** ("Initializing system…") and terminal-style command box (type `help`)
- **Live Discord presence** via the [Lanyard API](https://github.com/Phineas/lanyard)
- **Live Steam status** and the game I'm currently playing
- Gaming profile: platforms, top games (GTA V / FiveM RP, Valorant, PUBG, Minecraft), play style
- Contact section with links to GitHub, LinkedIn and Instagram
- Built with plain **HTML, CSS and JavaScript** in a single `index.html`

## 🚀 View it
Open `index.html` in a browser, or publish it for free with **GitHub Pages**: *Settings → Pages → Deploy from branch → `main`*.
